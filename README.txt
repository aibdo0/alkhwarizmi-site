شركة الخورزامي للتخليص الجمركي — موقع جاهز للرفع

1) ارفع index.html وstyle.css وscript.js وrobots.txt وsitemap.xml إلى public_html.
2) افتح script.js وعدّل WHATSAPP إلى رقم واتساب الشركة بصيغة دولية بدون + أو مسافات.
3) في index.html استبدل YOUR-DOMAIN.com بالدومين الحقيقي.
4) حدّث العنوان ورقم الهاتف والموقع في قسم "تواصل معنا".
5) واجهة متابعة السيارة الموجودة حاليًا تجريبية فقط؛ ربطها ببيانات العملاء يحتاج Backend/قاعدة بيانات.
6) يفضل إضافة شعار الشركة الحقيقي وبيانات التواصل الرسمية قبل النشر.
